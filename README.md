# Environmental-Noise-Pollution-Mapping
This project focuses on studying noise pollution using a real-world dataset.
The analysis explores how noise levels change based on time, weather, traffic conditions, and weekdays/weekends.
By examining patterns in the data, the project aims to understand the main factors that influence noise in an urban environment.
The dataset contains 2000 records and includes information like decibel level, date & time, temperature, humidity, wind, and traffic indicators.  
Using Python (Google Colab) and R Programming, the data was cleaned, explored, visualized, and summarized to identify meaningful trends.
The results show that noise pollution varies significantly by month, hour of the day, weather conditions, and human activity patterns. 
The findings highlight the importance of analyzing environmental data to support urban planning, noise-control policies, and better environmental management.
